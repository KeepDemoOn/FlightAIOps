# Interview Talking Points
- LangGraph gives explicit state, routing, retry/escalation and human approval checkpoints.
- Tool calling prevents the model from inventing operational facts.
- RAG grounds policy decisions in retrieved synthetic policy documents.
- Pydantic validates structured model output; deterministic Python validates capacity and percentages.
- Human-in-the-loop prevents autonomous execution of operational actions.
- Provider abstraction supports free local Ollama development and Azure OpenAI deployment.
- Evaluation scores grounding, arithmetic, safety, workflow completion and structured output.
